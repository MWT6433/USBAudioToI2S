**注意事项：**

1. 主存储器用于用户应用程序存储，按 **4K 字节（16 页）** 为单位进行写保护划分。除"厂商配置字"区域出厂锁定（用户不可访问）外，其他区域在一定条件下用户可操作。
2. FLASH 操作时**强烈建议系统主频 ≤ 120 MHz**。若必须超过 120 MHz：
   - 对非零等待区 FLASH、零等待区 FLASH、用户字读写、厂商配置字和 Boot 区读操作前，先将 **HCLK 2 分频**（相关外设时钟同时分频，影响需评估），操作完成后再恢复，保证 FLASH 访问时钟频率不超过 60 MHz。
   - `FLASH_CTLR` 的 bit[25] **SCKMOD** 可配置 FLASH 访问时钟为系统时钟或系统时钟的一半（默认：一半）。

## 32.2 闪存编程及安全性

### 32.2.1 两种编程/擦除方式

| 方式 | 编程粒度 | 擦除粒度 | 说明 |
|---|---|---|---|
| **标准编程** | 单次 2 字节（半字） | 4 K 页擦除、整片擦除 | 默认方式（兼容方式） |
| **快速编程** | 页操作（256 字节/页，推荐） | 256 B 擦除、32 K 擦除、64 K 擦除、整片擦除 | 需特定序列解锁 |

### 32.2.2 安全性——防止非法访问（读、写、擦）

- **页写入保护**（WRPR0–WRPR3 控制，每 bit 保护 4K 扇区）
- **读保护**（RDPR 字节控制）

芯片处于**读保护**状态下：
1. 主存储器 0–15 页（4K 字节）自动写保护，**不受 FLASH_WPR 控制**；解除读保护后，所有主存储页才由 FLASH_WPR 控制。
2. 系统引导代码区、SWD/SDI 模式、RAM 区域都**不可**对主存储器擦除或编程（整片擦除除外）；可擦除或编程用户选择字区域。若试图解除读保护（编程用户字），芯片将**自动整片擦除用户区**。

> ⚠️ 进行闪存编程/擦除操作时，必须打开内部 RC 振荡器（**HSI**）。

## 32.3 FLASH 增强读模式

- **适用场景**：用户程序运行在 FLASH 中，且用户代码空间超过选择字 `RAM_CODE_MOD[1:0]` 配置的 CODE 大小空间。
- **开启**：`FLASH_CTLR.EHMOD` 置 1。**关闭**：先将 `EHMOD` 清 0，再将 `RSENACT` 置 1。
- 通过 `SCKMOD` 位选择 FLASH 访问时钟频率。

**注意事项：**
1. 对 FLASH 进行**任何模式的擦除/编程**（含解除读保护等用户字编程）之前，须**先退出增强读模式**，否则擦除/编程失败。
2. **进入停止模式之前**须先退出增强读模式，否则可能导致停止模式异常。
3. 电源复位和系统复位结束后，硬件自动退出增强读模式。

```
31-8 Reserved | 7 EHMODS | 6 Reserved | 5 EOP | 4 WRPRTERR | 3-2 Reserved | 1 WRBSY | 0 BSY
```

| 位 | 名称 | 访问 | 描述 |
|---|---|---|---|
| 7 | EHMODS | RO | 增强读模式状态：1=开启，0=关闭 |

| 24 | EHMOD | RW | 增强读模式使能（1=开启）；关闭需先清 0 再置 RSENACT |

| 21 | PGSTRT | RW0 | 启动一次页编程（硬件自动清除） |
| 19 | BER64 | RW | 执行 64 KB 擦除 |
| 18 | BER32 | RW | 执行 32 KB 擦除 |
| 17 | FTER | RW | 执行快速页（256 B）擦除 |
| 16 | FTPG | RW | 执行快速页编程 |

| 12 | EOPIE | RW | 操作完成中断使能（EOP 置位时） |
| 10 | ERRIE | RW | 错误状态中断使能（PGERR/WRPRTERR 置位时） |
| 9 | OBWRE | RW0 | 用户选择字锁：1=可编程（正确序列后硬件置位），0=软件清零重新加锁 |
| 7 | LOCK | RW1 | 锁（只能写 1）：1=FPEC 与 FLASH_CTLR 锁定不可写。解锁失败后，**直到下次系统复位前不再改变** |
| 6 | STRT | RW1 | 启动一次擦除（硬件自动清 0，BSY 变 0） |
| 5 | OBER | RW | 执行用户选择字擦除 |
| 4 | OBPG | RW | 执行用户选择字编程 |
| 2 | MER | RW | 执行全擦除（擦除整个用户区） |
| 1 | PER | RW | 执行标准页（4 KB）擦除 |

## 32.5 闪存操作流程

### 32.5.1 读操作

通用地址空间内直接寻址，任何 8/16/32 位读操作均可访问闪存内容。

### 32.5.2 解除闪存锁

系统复位后 FPEC 和 FLASH_CTLR 锁定。解锁序列（**必须按序连续执行**，否则锁死 FPEC 与 FLASH_CTLR 并产生总线错误，直到下次系统复位）：

1. 向 FLASH_KEYR 写入 **KEY1 = 0x45670123**（第一步必须是 KEY1）
2. 向 FLASH_KEYR 写入 **KEY2 = 0xCDEF89AB**（第二步必须是 KEY2）

重新锁定：将 `FLASH_CTLR.LOCK` 置 1。

### 32.5.3 主存储器标准编程（半字 / 2 字节）

1. 检查 LOCK 位，为 1 则先解除闪存锁
2. 置 `FLASH_CTLR.PG = 1`，开启标准编程模式
3. 向指定闪存**偶地址**写入要编程的半字
4. 等待 BSY=0 或 EOP=1，将 EOP 清 0
5. 查询 FLASH_STATR 是否有错误，或读回地址校验
6. 继续编程重复 3–5 步；结束将 PG 清 0

![图 32-1 FLASH 编程流程图](fig32-1-program.png)

> 写入任何非半字数据，FPEC 产生总线错误。BSY=1 时禁止写任何寄存器。

### 32.5.4 主存储器标准擦除（页 4K / 整片）

闪存可以按标准页（4K 字节）擦除，也可以整片擦除。

**页擦除（图 32-2）：**

![图 32-2 FLASH 页擦除流程图](fig32-2-page-erase.png)

1. 检查 LOCK，为 1 则解除锁
2. 置 `PER = 1`（标准页擦除模式）
3. 向 FLASH_ADDR 写入所选页首地址（一次擦除 16 页）
4. 置 `STRT = 1`，启动擦除
5. 等待 BSY=0 或 EOP=1，清 EOP
6. 读擦除页数据校验；继续擦除重复 3–5 步，结束清 PER

**整片擦除（图 32-3）：**

![图 32-3 FLASH 整片擦除流程图](fig32-3-mass-erase.png)

1. 检查 LOCK，为 1 则解除锁
2. 置 `MER = 1`（整片擦除模式）
3. 置 `STRT = 1`，启动擦除
4. 等待 BSY=0 或 EOP=1，清 EOP
5. 读擦除页数据校验
6. 结束将 MER 清 0

> 擦除成功校验值：字读 = `0xe339e339`，半字读 = `0xe339`，偶地址字节读 = `0x39`，奇地址字节读 = `0xe3`。

### 32.5.5 快速编程模式解锁

向 FLASH_MODEKEYR 依次写入 KEY1、KEY2（同样必须按序连续，否则锁定直到下次系统复位）。解锁后 `FLOCK` 清 0；重新锁定可将 FLOCK 软件置 1。

> ⚠️ 快速编程操作需要解除 **LOCK** 和 **FLOCK** 两层锁定。

### 32.5.6 主存储器快速编程（页 256 字节）

1. 检查 LOCK，为 1 则解除闪存锁
2. 检查 FLOCK，为 1 则执行快速编程模式解锁
3. 检查 BSY，确认无正在进行的编程
4. 置 `FTPG = 1`，使能快速页编程
5. 用 **32 位方式**向 FLASH 地址写入数据，如 `*(uint32_t*)0x80000000 = 0x12345678;`
6. 等待 `WRBSY = 0`，写入下一数据
7. 重复 5–6 共 **64 次**（64 × 4 B = 256 B）
8. 置 `PGSTRT = 1`，启动快速页编程
9. 等待 BSY=0 或 EOP=1，清 EOP
10. 查询错误或读回校验
11. 继续编程重复 5–10 步；结束清 FTPG

### 32.5.7 主存储器快速擦除

**页擦除（256 B）：** 解 LOCK/FLOCK → 查 BSY → 置 `FTER=1` → FLASH_ADDR 写页首地址 → 置 `STRT=1` → 等 BSY=0/EOP=1 → 清 EOP → 校验 → 结束清 FTER。

**块擦除（32 K）：** 同上，置 `BER32=1`（块首地址）。

**块擦除（64 K）：** 同上，置 `BER64=1`（块首地址）。

> 擦除成功校验值同上：字读 `0xe339e339`、半字读 `0xe339`、偶地址字节 `0x39`、奇地址字节 `0xe3`。

## 32.6 用户选择字

用户选择字固化在 FLASH 中，系统复位后重新装载到相应寄存器，可任意擦除/编程。信息块共 **8 字节**：4 字节写保护 + 1 字节读保护 + 1 字节配置选项 + 2 字节用户数据；**每个位都有反码位用于装载校验**。

### 表 32-3 32 位选择字格式

| [31:24] | [23:16] | [15:8] | [7:0] |
|---|---|---|---|
| 选择字字节 1 反码 | 选择字字节 1 | 选择字字节 0 反码 | 选择字字节 0 |

### 表 32-4 用户选择字信息结构

| 地址 | [31:24] | [23:16] | [15:8] | [7:0] |
|---|---|---|---|---|
| 0x1FFFF800 | nUSER | USER | nRDPR | RDPR |
| 0x1FFFF804 | nData1 | Data1 | nData0 | Data0 |
| 0x1FFFF808 | nWRPR1 | WRPR1 | nWRPR0 | WRPR0 |
| 0x1FFFF80C | nWRPR3 | WRPR3 | nWRPR2 | WRPR2 |

### 字段说明

| 名称 | 复位值 | 描述 |
|---|---|---|
| **RDPR**（读保护） | 0x01 | `0xA5`（且 nRDP=`0x5A`）＝非读保护，代码可读出；**其他值＝读保护**，代码不可读，且 0–31 页（4K）自动写保护，不受 WRPR0 控制 |
| **USER[7:6]** RAM_CODE_MOD | xxb | 代码/RAM 划分。**CH32V30x_D8C/D8、CH32F20x_D8C/D8**：00=CODE-192KB+RAM-128KB；01=224K+96K；10=256K+64K；11=288K+32K。**CH32V20x_D8W/D8、CH32F20x_D8W**：00=128K+64K；01=144K+48K；1x=160K+32K |
| USER[5:3] | 1 | 保留 |
| USER[2] STANDYRST | 1 | 待机复位：1=不启用（待机不复位），0=启用（待机产生系统复位） |
| USER[1] STOPRST | 1 | 停止复位：1=不启用，0=启用 |
| USER[0] IWDGSW | 1 | IWDG 使能：1=由软件开启，0=由硬件开启（随 LSI 时钟） |
| **Data0–Data1** | FFFFh | 用户数据 2 字节 |
| **WRPR0–WRPR3**（写保护） | FFFFFFFFh | 每 bit 控制主存储器 1 个扇区（4K/扇区）：**1=关闭写保护，0=启用写保护**。4 字节共保护 512K 主存储器：WRPR0→扇区 0–7；WRPR1→扇区 8–15；WRPR2→扇区 16–23；WRPR3 位 0–6→扇区 24–30，**位 7→扇区 31–127** |

### 32.6.1 用户选择字解锁

向 FLASH_OBKEYR 依次写入 **KEY1 = 0x45670123**、**KEY2 = 0xCDEF89AB**（按序连续）。解锁后 `OBWRE` 置 1；软件清 0 可重新锁定。

> ⚠️ 用户选择字操作需要解除 **LOCK** 和 **OBWRE** 两层锁定。

### 32.6.2 用户选择字编程

**只支持标准编程方式，一次写半字（2 字节）。** FPEC 只使用半字中的**低字节**，并自动计算高字节（低字节的反码）后编程，保证字节与反码始终匹配。

1. 检查 LOCK，为 1 则解除闪存锁
2. 检查 BSY，确认无正在进行的编程
3. 检查 OBWRE，为 0 则执行用户选择字解锁
4. 置 `OBPG = 1`
5. 写入要编程的半字到指定地址
6. 等待 BSY=0 或 EOP=1，清 EOP
7. 读回校验；继续编程重复 5–7 步，结束清 OBPG

> ⚠️ 修改选择字使"读保护"变为"非保护"状态时，**自动执行一次整片擦除主存储区**；修改读保护之外的选项则不会整片擦除。

### 32.6.3 用户选择字擦除

**直接擦除整个 128 字节用户选择字区域。**

1. 检查 LOCK，为 1 则解除锁
2. 检查 BSY
3. 检查 OBWRE，为 0 则解锁
4. 置 `OBER = 1`，再置 `STRT = 1`，开启用户选择字擦除
5. 等待 BSY=0 或 EOP=1，清 EOP
6. 读擦除地址数据校验
7. 结束清 OBER

> 擦除成功校验值：字读 = `0xe339e339`，半字读 = `0xe339`，字节读 = `0x39`。

### 32.6.4 解除读保护

读保护由用户选择字决定（`FLASH_OBR.RDPRT = 1` 表示读保护有效）。解除流程：

1. **擦除整个用户选择字区域**（此时 RDPR 字段被擦除，但读保护仍然有效）
2. **用户选择字编程**，写入正确 RDPR 码 `0xA5` 以解除读保护（此步骤先导致系统自动对闪存执行**整片擦除**）
3. **上电复位**重新加载选择字节（含新 RDPR 码），读保护解除

### 32.6.5 解除写保护

写保护由用户选择字决定（`FLASH_WPR` 每 bit 代表 4K 字节，1=非写保护，0=写保护）。解除流程：

1. 擦除整个用户选择字区域
2. 写入正确的 RDPR 码 `0xA5`，允许读访问
3. **系统复位**重新加载选择字节（含新的 WRPR[3:0]），写保护解除
